# 🌍 TripNest – Tourism Management System

TripNest is a modern **Tourism Management System** built using **ASP.NET MVC**.  
It allows tourists to explore tours, agencies to manage trips, and admins to control the platform.

> **Tagline:** Discover. Book. Explore.

---

## 🚀 Features

### 👤 Tourist
- Register & login
- Browse tour packages
- Book tours
- View booking status
- Make payments

### 🏢 Agency
- Create agency profile
- Publish tour packages
- View bookings
- Approve or reject bookings

### 🛠️ Admin
- Dashboard with statistics
- Manage users
- Manage agencies
- View all bookings
- Approve agencies

---

## 🧱 Technology Stack

| Layer | Technology |
|------|------------|
| Frontend | HTML, CSS, Bootstrap |
| Backend | ASP.NET MVC |
| Authentication | ASP.NET Identity |
| Database | SQL Server |
| ORM | Entity Framework |
| Version Control | Git + GitHub |

## ⚙️ How to Run the Project

1. Clone the repository
git clone https://github.com/pankajgangwar9/TripNest.git

2. Open `TourismManagementSystem.sln` in Visual Studio  
3. Restore NuGet packages  
4. Update database (Entity Framework migrations)  
5. Run the project
